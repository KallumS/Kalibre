# 0034. Sync: MIDI clock, timecode and Ableton Link

## Context

Drum machines, synths, video and other computers need to keep time with Kalibre, or Kalibre with them.

## Decision

Sync is set up per Mac (the Studio tab, `ControlSettings`, saved in Application Support), not per song. MIDI clock out sends 24 pulses a beat with Start, Stop, Continue and Song Position, timed to the sample and to when the block is heard; round the loop it sends Stop, the loop's start and Continue. MTC out sends quarter frames and a full frame on every locate. Clock in is followed for tempo (while the song has a single tempo), start, stop and position. Ableton Link (GPL v2 or later, which combines with Kalibre's AGPL) shares tempo, start and stop, and with others in the session Kalibre waits for the session's next bar before starting. The arithmetic (`Core/Sync`) is tested without JUCE; the sending is `Engine/SyncDevices`.

## Consequences

- Following a clock moves the tempo, not the playhead's phase: long runs can drift by a fraction of a beat.
- A song with tempo changes keeps its own tempos even with Link or a clock coming in.
- Not tried with real gear yet.
