# 0042. MPE

## Decision

A track set to MPE (track menu) plays each note on a channel of its own, 2-16, the one free longest, with the zone set up by RPN 6 at the start. A note carries its own expression (`Note::expression`: bend in semitones, pressure, slide/CC 74). Recording from an MPE controller turns each channel's bends, pressure and CC 74 into its note's expression; the piano roll's Note Bend, Note Pressure and Note Slide lanes draw it (the chosen notes, or all sounding there). `Core/Mpe`, tested.

## Consequences

- Bend range is MPE's default 48 semitones; the lane shows two octaves.
