# 20 November 2026

Asked: the latest build failed; read the docs and look into it.

- CI runs 175, 178 and 179 (the pull request and the merge to main) failed
  one app test, on the Mac and on Linux: *sampler: Speed in Keys is tape;
  Granular keeps the pitch at half speed* (`TestEngine.cpp:1283`). The same
  commits had passed on their branch pushes (174, 177).
- Cause: Kalibre Sampler's Granular Spray takes its chance from
  `juce::Random`, seeded from the clock. Each run sprayed the grains
  differently; now and then the overlapping grains blurred the pitch the test
  measures. Here, 2 runs in 40 failed. The same chance also meant an export
  of a granular note was never the same twice, against 0097.
- Fixed: each voice's chance starts from a fixed seed in `prepareToPlay` and
  `reset` (`KalibreSampler::seedGrains`). A new test failed first (two plays
  from a reset differ; a second sampler differs), and passes now. The pitch
  test now measures 440.9 Hz every time (it allows 5 Hz either way).
- 0097 amended; DEVICES.md's Spray says so. Tests: 214 core, 160 app (1 new), all passing here.

## Later: song versions 1 and 2; versions not playing unloaded (0103)

Asked: two versions of the whole song, 1 and 2 in the top bar, working like
a track version, worth it only if the one not playing costs little processor
and memory, unloaded like a frozen track. Asked back three things; answered:
each version its own tempo, markers and key; choosing is an undo step; track
versions unload the same way.

- **Song versions**: the other version kept as its saved JSON
  (`Project::otherVersion`), shared between Undo's snapshots. Name, details,
  timer and sample rate shared. `edit::newSongVersion`, `selectSongVersion`,
  `deleteSongVersion` in Core; saved inside the `.kalibre` file.
- **Choosing**: plug-in settings taken, the engine lets go of every plug-in
  and makes the chosen version's (`songId` says when). Making version 2
  reloads nothing. Plays on if it was playing; refused while recording.
- **Audio**: the cache forgets what no clip asked for at the last sync
  (`AudioCache::forgetUnused`), so the other version's audio leaves memory
  (and old warp renders, which had piled up before).
- **Track versions**: only the playing one's plug-ins are made; parking gone.
- **Undo across a switch** carries what was changed since into the version
  left (`Controller::carryPlayingStates`): a test failed without it.
- Unfreezing keeps a render the other version still plays.
- Top bar: 1 and 2 left of Random; 2 grey until made; right-click to Delete.
  Agents: `song_version`, and `get_song` says which plays.
- Render 41 (`docs/guide/song-versions.png`); USER-GUIDE, FEATURES,
  ARCHITECTURE, AGENTS, 0050 amended.

Tests: 216 core (2 new), 164 app (4 new, one changed: 0050's "kept loaded"
became "unloaded"), all passing here. Not yet tried on the Mac: how long
choosing takes with big sample libraries.
