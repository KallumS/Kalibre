# 17 November 2026 (continuing from the night of the 16th)

Asked (the 16th, late): add some of the user's repos as devices: Midi
Evolver, Instant Virtual Instrument, Transient Shuffler, Midi Catalogue,
Starting Blocks, Starting Blocks Notation, Orchestration Helper, Reese
Basser, Reverberator and Instrument Creator. Then: the repos' branches might
help. They did: Reverberator, Reese Basser and Instrument Creator have a
`plugin` branch with a JSFX wrapper; Starting Blocks and its Notation a
`plugin` branch that runs the ReaImGui window as a plug-in; Orchestration
Helper a Mac app that runs its gfx script.

Built, in three stages, each tested first and its Mac build passing:

1. **The JSFX** (0066): the five files, unchanged, run by ysfx (REAPER's
   EEL2 engine, fetched by CMake) through a device adapted from the plugin
   branches' wrapper: sliders as parameters, state saved, each JSFX's own
   window, MIDI it sends passed on (Midi Evolver plays the synth after it).
2. **Instant Virtual Instrument** (0067): its source, unchanged, compiled in,
   through `HostedProcessor`, which makes any JUCE processor a device. Found:
   a value set from Kalibre wasn't kept in its saved state until its own
   listeners were told, as a plug-in format's wrapper does.
3. **The ReaScripts** (0068): Lua built as C++ first (as the plugin branch
   builds it). Starting Blocks, its Notation and Midi Catalogue (no plugin
   branch, but written the same way) share one host from the plugin branch,
   Dear ImGui fetched by CMake, the block handed to the audio thread through
   a `Swap` rather than the plug-in's lock. Kalibre's own stand-ins for their
   REAPER placement: Insert at Cursor puts the block on the device's track at
   the playhead, Midi Catalogue's sections a new track per instrument, one
   undo step. Orchestration Helper runs through a port of its Mac host,
   drawn with JUCE; typing "trombone" finds its page (render).

Renders 21, 22 and 23 (each tool in the rack); screenshots in the README.

Tests: 150 core, 62 app.
